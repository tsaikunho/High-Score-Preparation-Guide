甄試方式：筆試 / 口試

## 筆試說明：
1. 「筆試」成績比重佔 50%。
2. 「筆試」試題以測驗題為出題原則：
- 試題範圍：單複選題，網頁設計與電腦相關常識、數理邏輯推理能力。
- 題型範例：請至【本分署網站➜職業訓練➜自辦訓練專區➜甄選試題專區】自行參考。 3.「筆試」測驗開始 15 分鐘後不得進入試場應試，並以缺考論。

## 口試說明：
1. 「口試」成績比重佔50%。
2. 「口試」以問答方式進行，項目及權重包含參訓歷史、求職歷程、表達能力與團體適應能力、參訓動機與適訓性、訓後生涯規劃與就業意願等適性問答。
